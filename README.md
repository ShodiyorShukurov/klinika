# Klinika

Multilingual website for a medical clinic — services, case studies, video showcase, and contact with an interactive map.

## Features

- Service catalog with detail pages
- Multilingual UI with i18next
- Hero and case-study carousels (Swiper)
- Video showcase section
- Contact section with Google Maps integration

## Tech Stack

React · TypeScript · Vite · Tailwind CSS · i18next · Swiper · Google Maps

## Run locally

```bash
npm install
npm run dev
```
